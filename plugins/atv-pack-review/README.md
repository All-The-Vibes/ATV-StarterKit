# atv-pack-review

Code review pack — multi-agent CE Review and document review skills for catching issues early.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-review`). The granular `atv-pack-review` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
