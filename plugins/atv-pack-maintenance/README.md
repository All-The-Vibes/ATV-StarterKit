# atv-pack-maintenance

Maintenance & health pack — atv-doctor (diagnose ATV install health) and atv-update (update marketplace plugins; advisory for project scaffold). Keep your ATV install healthy and current.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-maintenance`). The granular `atv-pack-maintenance` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
