# atv-pack-shipping

Shipping & deploy pack — Takeoff, CE Work, Land, LFG/SLFG orchestrators, and CE Compound for executing and delivering work.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-shipping`). The granular `atv-pack-shipping` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
