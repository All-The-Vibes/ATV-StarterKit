# atv-pack-planning

Planning & design pack — Brainstorming, CE Brainstorm, CE Ideate, Plan, and Deepen Plan skills for shaping work before coding.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-planning`). The granular `atv-pack-planning` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
