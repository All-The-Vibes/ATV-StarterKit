Easter eggs pack — fun extras like memeIQ for AI-powered meme generation.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

The granular `atv-pack-easter-eggs` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
