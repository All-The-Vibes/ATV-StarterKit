# atv-pack-learning

Learning pipeline pack — Learn, Instincts, Evolve, and Observe for compounding institutional knowledge across sessions.

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-learning`). The granular `atv-pack-learning` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
