# atv-pack-security

Security pack — unified ATV Security skill that audits both agentic configuration and application source code (OWASP Top 10 + STRIDE).

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-security`). The granular `atv-pack-security` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
