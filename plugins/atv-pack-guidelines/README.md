# atv-pack-guidelines

Coding guidelines pack — Karpathy Guidelines (behavioral) plus Autoresearch (autonomous experimentation loop).

## Install

```bash
copilot plugin marketplace add All-The-Vibes/ATV-StarterKit
copilot plugin install atv-starter-kit@atv-starter-kit
```

> The Copilot CLI marketplace exposes a single installable plugin, `atv-starter-kit`, which bundles every ATV skill and agent (including `atv-pack-guidelines`). The granular `atv-pack-guidelines` entry in `.github/plugin/marketplace.json` is not individually installable through the Copilot CLI today.
